# Development Principle
Please write your api inside api directory and add it to app via api_service(), meanwhile you need to document the api function itself via utoipa macros.  
SwaggerUI: http://localhost:8080/swagger-ui/index.html
OpenAPI json: http://localhost:8080/api/openapi.json
